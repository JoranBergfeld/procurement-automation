# Assumptions

This directory records material, non-obvious assumptions used across the repository. It is a public repository: keep records safe to publish and refer to confidential evidence only through a sanitized pointer to its authorized storage.

Each topic record distinguishes assumptions from verified evidence and settled decisions. Include:

- status (for example, planning assumption, conditional, validated, rejected, or retired)
- the assumption and why it matters
- supporting evidence, uncertainty, and source decision links
- impact if it is false
- validation owner and trigger, or `Unknown`

For Wayfinder work, the issue resolution is the canonical decision; these files are supporting records linked from the issue.
